# fox-berg.com

the for-sale page for fox-berg.com. same catppuccin windows as [3hz.dev](https://3hz.dev),
[mitchellberg.org](https://mitchellberg.org) and [naftaliro.dev](https://naftaliro.dev).
plain html, css and js, no build step.

| file | what it is |
| --- | --- |
| `index.html` | the whole page: one window with the listing and the offer button |
| `404.html` | for the bots looking for `/.env` |
| `assets/css/style.css` | palettes at the top, then the bar, the window, the listing |
| `assets/js/main.js` | flavor switcher, clock, and the 3hz prairie wallpaper |
| `assets/fonts/` | iosevka and silkscreen, the same subsets 3hz.dev uses |
| `assets/img/og.png` | the link preview picture |
| `_tools/icons.py` | draws the pixel fox favicons. no pip installs: `python3 _tools/icons.py` |

## when it sells

turn off pages (or delete the repo) before the transfer. github only lets one
pages site claim a domain, so the new owner can't use fox-berg.com there until
this one lets go.
